What's new

  • Page N chip on PDF page-anchor recents. Preview and Skim entries that point at a specific page now show "Page 42" in the chip instead of a generic "PDF" label, matching the page captured at copy time.
  • "Copied page N" tooltip. After copying a PDF page anchor, the tooltip names the page directly rather than saying "Copied PDF page".
  • History migrates forward. Pre-1.11 entries with #page=N URL fragments pick up the new chip on next launch — no need to re-capture.
