What's new

  • Richer Spotify tooltip. Hovering a Spotify track in Recents now shows a larger album cover with the track, artist, and album on separate lines. Auto-hide is bumped to five seconds so the artwork has a beat to land.
  • Re-show the hover tooltip with ←. Press the left arrow with no modifiers to bring the tooltip back for the focused row after Esc or the auto-hide timer dismissed it.

What's fixed

  • In-app updates work again. Pinza stamped its build number from the git commit hash, which sort-compared randomly — so Sparkle on 1.11.0 could never see 1.12.0 as a newer release. The build number is now a date-time timestamp, so future updates land via "Check for Updates…" as expected. Everything from 1.12.0's release notes still applies.
