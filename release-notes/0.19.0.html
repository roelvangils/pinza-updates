New

  • Apple Books support. Press Pinza's shortcut in Books to copy the canonical books.apple.com URL of the book you're reading, with cover art in the hover preview. Resolves the focused reader window's title against the iTunes Search API; falls back to a Books store search URL when the title is ambiguous, and copies nothing for personal EPUBs that aren't in the catalog.
  • Copy as… formats. New submenu on the HUD and popover context menu offers alternative renderings of the same path or URL: Git-relative path, Absolute path, Tilde path (with and without quoting), AppleScript-style colon path, file:// URL, vscode:// URL, SCP host:path, Markdown link, HTML anchor, ROT13, SHA-256 hash, Base64 Data URI, and raw Base64.
  • Richer Podcasts metadata. Episode title, duration, release date, and synopsis now ride along on copied podcast entries — surfaced in the hover Card and searchable from the recents list.
