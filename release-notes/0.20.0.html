What's new

Drag the HUD's icon out as a proxy icon. Grab the leading icon on the post-copy HUD and drop it straight into Finder, Safari, a text editor, anywhere that accepts a file / URL / link drop. Same payload as clicking the row — now reachable as a drag gesture. Hold ⌥ during the drop to keep the HUD open with a fresh countdown for another grab.

Rename files in place. Double-click the title on a file-backed HUD to swap it for an editable field. Press Return to commit; Esc cancels. Changing the extension surfaces a Finder-style "Are you sure you want to change the extension" confirmation with a one-click ⌘Z undo on the success card.

Drop-zone polish when repositioning the HUD. The six drop targets that appear while dragging the HUD between screen anchors now fade in with a per-zone cascade, sit on Liquid Glass (Tahoe) / .ultraThinMaterial chrome, and the active target lifts with a subtle white wash. On release the HUD glides to its anchor with an ease-out curve, the action row auto-expands, and the countdown restarts from full.

Notification-style close button. The × on the HUD now sits at the top-leading corner with a soft drop shadow and pops larger when the cursor approaches — matching macOS Notification Center's pattern.

Under the hood

  • Build-iteration speed-ups: framework re-embed cache, incremental resource sync, file splits, and SwiftUI body extractions cut a MenuBarView.swift typecheck pass from ~9 s to ~0.4 s.
  • make profile-typecheck diagnostic target surfaces slow SwiftUI bodies before they accrete.
  • QuickLookPresenter @MainActor conformance now isolated to the main actor (Swift 6 readiness).
  • /run-dev skill reports build time, framework cache state, resource-sync status, and any warnings.

Compatibility

Requires macOS 14 or later. macOS 26 (Tahoe) gets Liquid Glass surfaces on the new HUD chrome; earlier versions fall back to .ultraThinMaterial.
