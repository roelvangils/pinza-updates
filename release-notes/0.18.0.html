Refreshed post-copy HUD

The HUD that shows after a copy got a thorough polish pass — bigger icon and bolder document title, a tighter type hierarchy, and a clean entry without the brief flash of square corners. The path / URL line is now set in JetBrains Mono NL (bundled), which reads much better than Apple's system monospace.

Quicker keyboard interaction

  • Press your copy shortcut a second time with the HUD up to expand the action row. Press it again to collapse — no more accidental fresh copies when Pinza grabs your focus.
  • The expanded HUD takes keyboard focus without activating Pinza, so Tab cycles through the buttons (Remind me… → Remove from History) and Escape dismisses. Your previous app stays in the foreground.
  • A small × close button appears in the top-right when you hover.

Confirmation moments

Picking Remind me…, Remove from History, or any Copy as… option now plays a centered confirmation inside the HUD ("Reminder set", "Removed from History", "Copied as Markdown") — content blurs behind, the HUD auto-dismisses 2 seconds later. The old floating toast is gone. Press the shortcut during the 2 s if you want to undo the dismissal and pick something else.

Animation behaviour

Every expand / collapse / hover toggle now uses the same bouncy spring — not just the first interaction. Settings → General → Use Animations is now the single source of truth: On always animates, Off snaps everything instantly, Follow System defers to macOS Reduce Motion.

Small fixes

  • The Remind me… menu chrome now matches its sibling buttons exactly (single Liquid Glass pill, no inner border).
  • The "Reminder set" message no longer appears twice when triggered from the HUD.
