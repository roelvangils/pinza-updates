New

  • Themed Spotify tooltip: album-art-derived accent color forms the background, with an inline 80×80 cover and a 💿 sliding out from behind it on hover.
  • Wraparound keyboard nav: pressing ↓ on the last recents row jumps to the top; ↑ on the first row jumps to the bottom.
  • Hidden utility rows: Check for Updates, Settings, and Quit are hidden by default and slide in during ⌘⌥ Power Peek.
  • ⌘U triggers a manual update check from anywhere in the popover.
  • ⌘← reopens the hover tooltip after it's been dismissed (Esc, auto-hide, or any earlier keystroke).
  • ⌘← dismisses the row actions menu — symmetric with ⌘→ opening it.

Improved

  • Poof + sound on delete: deleting recents rows plays the macOS poof animation with the real Dock-poof sound (toggleable in Settings).
  • Focus-after-delete: deleting a row keeps the next row selected so you can chain ⌫ presses.
  • Auto-focus on commit: pressing ↵ on the primary-copy button now selects the newly-added entry and shows its tooltip — no arrow-down required.
  • Unified tooltip layout: single canonical layout with shared chrome, larger title, footer bar with usage stats or keyboard tip, character-wrapped URLs.
  • Power Peek font bumped 1pt for readability.
  • Bottom anchored tooltip footer bar for every link type with usage info or keyboard hints.

Fixed

  • Marquee no longer scrolls all rows simultaneously under ⌘⌥ Power Peek.
  • Pressing ⌘→ while the tooltip is visible no longer also opens the context menu — it just dismisses the tooltip.
