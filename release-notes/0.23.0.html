What's changed

The biggest release yet — a rebuilt launcher, a new Pro tier, Raindrop.io support, and custom copy formats.

Pinza Pro

A paid tier arrives, with licensing through Gumroad. Pro unlocks Spotlight indexing of your recents, token search filters in the popover, longer history retention, the Bin, and the MCP server.

Launcher and HUD

The launcher has been rebuilt around pin groups: name them, sort them, and drag items between them for real. Pin several items at once from Finder or Things, and drag a whole selection in one go. The HUD gains stacked-card animations, flip-to-reveal, and double-click to pin. YouTube links now preview with a poster, channel row, and subtitle snippets.

Raindrop.io

Save any copied link straight to Raindrop with ⌘D from the HUD. The save popover has a proper combo box, tag autocomplete, and full keyboard access.

Custom copy formats

Build your own output templates with a template editor and snippet library, managed from a new Actions pane. The card notes editor picks up ⌘B / ⌘I / ⌘K for Markdown.

Recents

Recents now group under Pinned / Today / Yesterday headers, with tinted SF Symbol badges for well-known sites and an optional Compact mode for denser rows. History can be exported and imported as JSON.

Settings, onboarding and accessibility

Onboarding is rebuilt as a seven-step flow with an intro video and a live shortcut recorder. The Settings window gets a full-height sidebar and glass search. A new Accessibility pane adds Reduce Motion and High Contrast overrides, and High Contrast now carries through the app's chrome. Settings mirror to ~/.config/pinza/config.json.

App support

Safari Web Apps (Add to Dock PWAs) are supported via a new generic strategy. System Settings panes fall back to AppleScript on macOS 27, and browser-highlight capture is noticeably faster thanks to a text-marker fast path.

Fixes

  • Fixed a main-thread freeze when building Spotlight items
  • Fixed a launcher hang caused by pin-list sorting and on-main icon resolution
  • Fixed a crash when closing onboarding
  • Survived macOS 27's ViewBridge crash in the Raindrop popover
  • The launcher no longer misreports counts while rows are stale
  • Automatic TCC resets are now limited to once per target per session
