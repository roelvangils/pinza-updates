Pin groups + group filtering

Right-click a selection of pins to Group them — or Group as… to name on creation. Right-click a single pin to Move to Group an existing one or create a new one inline. Members of a highlighted group light up with a soft yellow band, and the active group's name surfaces as a pill in the hint bar.

Type two characters in the search field and matching group chips appear below it. Click to filter the recents list to that group; ⌘-click to OR-combine. The chips persist across a cleared search field — explicit × to dismiss, with a 2 s grace window so a misclick is recoverable. The search placeholder reads Search 12 pins and 3 groups… normally, Search 7 pins in 2 groups… while filtering.

⌘A now cycles: group → all visible → back to group. Group mutations are undoable — ⌘Z reverts a Group / Ungroup / Move to Group / Rename, ⌘⇧Z replays.

Polish

  • Finder-style merged selection — a run of adjacent selected rows reads as one continuous rounded shape, regardless of where the colour shifts inside it (yellow ↔ pink ↔ orange).
  • Ungroup verb — when the action would dissolve a group entirely (singleton row, full multi-selection), the right-click item reads "Ungroup" instead of "Remove from Group".
  • Counted Remove — partial multi-selections show Remove 3 items from Group "Trip planning" so the action is honest about its scope.
  • Search-match font — the matched portion of a title no longer shrinks mid-line.
  • Rename dialog — the NSAlert text field is now focused on appear, and the popover stays put while the rename is in flight.
